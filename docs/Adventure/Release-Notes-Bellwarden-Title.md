# Release notes — Shandalar Ascendant (title)

Player-facing Adventure title for this Forge build is **Shandalar Ascendant** (window title, world picker,
menus, dialogs, and docs). A brief rename to "Bellwarden: Planes of Nothing" was reverted.

Steve's separate game, **Bellwarden**, is documented under [`docs/Bellwarden/`](../Bellwarden/); that project
gets the real co-op on Godot. It is not this Forge build.

- Stock **Shandalar** and other Adventure worlds are unchanged.
- The Standard format displays as **Shandalar Standard** (old Bellwarden / Bellwarden Standard input aliases
  still resolve). Completionist title display is **Shandalar Completionist** (stored id unchanged).
- Internal content-pack folder `Shandalar Ascendant`, save keys, `Config.ascendant()`, and protocol strings are
  unchanged; old saves load without migration.
- Built on Forge; Forge engine credit and GPL attribution remain intact (see `CREDITS.md`).
