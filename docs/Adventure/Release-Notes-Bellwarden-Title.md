# Release notes — Bellwarden: Planes of Nothing (title)

The Adventure mode formerly shown as **Shandalar Ascendant** / **Forge Ascendant** / **Ascendant** is now
named **Bellwarden: Planes of Nothing** in the window title, world picker, menus, dialogs, and docs.

- Stock **Shandalar** and other Adventure worlds are unchanged.
- Internal content-pack folder `Shandalar Ascendant`, save keys, `Config.ascendant()`, and protocol strings are
  unchanged in this change; a later migration PR will rename those.
- Built on Forge; Forge engine credit and GPL attribution remain intact (see `CREDITS.md`).
